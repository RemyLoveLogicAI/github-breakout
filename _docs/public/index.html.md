## Overview

This HTML file provides a simple single-page UI for generating an animated Breakout-style SVG based on a GitHub contribution graph. It includes a form where a user can enter a GitHub username, choose a theme (including some predefined color arrays), and toggle a "ghost" option for showing inactive days. When the form is submitted, client-side JavaScript builds query parameters and calls an API endpoint (/api/breakout) to retrieve the generated SVG, then inserts that SVG into the page and updates a status area to show progress or errors. The page uses Tailwind CSS for styling and includes a footer linking to the project repository.
